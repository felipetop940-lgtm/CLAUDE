# Alessandra Silveira · sistema visual

Base: manual da marca (feito pela Vitória). Usado nos três sites (Goiânia, Trindade, IPASGO).

## Cores
| Token | Hex | Uso |
|---|---|---|
| `--forest` | #546250 | Cor principal da marca: seções escuras, etiquetas, ícones, títulos |
| `--forest-3` | #3B4538 | Rodapé e fundo do mar do iceberg (tom derivado, mais escuro) |
| `--sage-2` | #939C89 | Sálvia da marca: só decorativo (linhas, pontos); não usar em texto |
| `--linen` | #FBF0E4 | Creme da marca: fundos claros |
| `--sand` | #F4D9B9 | Pêssego da marca: destaques sobre o verde, seções "Para quem" e "Depoimentos" |
| `--ink` | #2E362C | Texto principal (verde quase preto, derivado) |
| `--wa` | #25D366 | Só botões de WhatsApp (regra 4) |

## Tipografia
- **Forum** (secundária da marca): todos os títulos, peso único 400.
- **Allura**: palavras de destaque curtas (`<em>`). Substitui a Le Jour Script, que não tem licença web livre; trocar quando houver o arquivo licenciado.
- **Plus Jakarta Sans**: texto corrido, botões e menus (legibilidade para pacientes mais velhos).

## Logo
- `assets/img/logo-arvore.webp` + `logo-nome.webp`: cabeçalho (verde, fundo transparente).
- `logo-claro.webp`: versão creme para fundo verde (abertura e rodapé).
- `logo-completo.webp`: árvore + nome em verde, para fundos claros.
Extraídas do manual em PNG; trocar pelos arquivos vetoriais originais quando chegarem.

## Componentes
Botão WhatsApp (verde), botão escuro (forest), etiquetas forest com texto creme, cartões brancos com borda #E9DCCB, foto com bloco verde deslocado (topo) ou contorno fino deslocado (Sobre).
